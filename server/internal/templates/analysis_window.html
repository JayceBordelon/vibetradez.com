The daily session now runs under a one hour window instead of nine minutes, so a research heavy session can finish instead of ending early.

VibeTradez · product update

A longer analysis window

A change shipped this morning that affects how the portfolio manager runs each day. Until now, the daily session ran under a nine minute limit. A session that starts from cash and does heavy research, such as web searches, price history across several names, and the occasional code run, could reach that limit before it finished and end with no decisions recorded for the day.

The session window is now one hour. That is enough headroom for the model to complete its research and place its trades on a slow day without being cut off partway through.

Failed runs are no longer silent

The manager now fails safe. If a session ends before it commits anything, it records a clear no action stance instead of leaving a blank day. A failed run shows on the dashboard and in the daily recap rather than passing unnoticed. Any orders that already reached the broker are kept, and a real stance the model produced is never overwritten.

More detail in the transcripts

The session transcripts now report more about each run:

Duration and cost. Each session shows how long it ran, the tokens it used, and an estimated cost, broken out as a line item table.

Reasoning. The model's summarized reasoning between tool calls is now shown, so the steps it took are easier to follow.

Code output. When the model runs code during research, the output it produced is captured in the transcript alongside the rest of the run.
